🌦️ Weather App

A responsive weather application that allows users to search for a city and view its current weather conditions and a 5-day forecast. The application displays temperature, feels-like temperature, humidity, wind speed, and precipitation through a clean and user-friendly interface.

✨ Features
🔍 Search for weather information by city name.
🌡️ Display current temperature and feels-like temperature.
☀️ Show current weather conditions.
💧 Display humidity, wind speed, and precipitation.
📅 Provide a 5-day weather forecast.
📱 Clean and responsive user interface.
🐳 Deploy the application using a pre-built Docker image.
☁️ Host the application on an AWS EC2 instance.

🛠️ Technologies Used
Frontend: Web technologies used in the application
Backend: Node.js
Container Platform: Docker
Cloud Platform: AWS EC2
Development Tools: Visual Studio Code, Git, and GitHub

🚀 Deployment

The Weather App was deployed on an AWS EC2 instance using an existing Docker image. The image was used to run the application in a Docker container on the EC2 server, making the application accessible through the instance's public IP address.

🎯 Project Objective

The objective of this project was to gain practical experience in deploying a web application on AWS EC2 using Docker, working with Docker images, and making a cloud-hosted application accessible over the internet.
